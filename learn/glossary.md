# Glossary

[Course index](README.md)

| Term | Meaning |
|---|---|
| **Adjusted R²** | R² penalised for the number of regressors; can fall when a useless variable is added |
| **AIC / BIC** | Information criteria: fit (log-likelihood) minus a penalty for parameters; lower is better; BIC penalises more |
| **Autocorrelation** | Correlation of a series (or residuals) with its own past values |
| **BLUE** | Best Linear Unbiased Estimator: OLS under the Gauss–Markov assumptions |
| **Block bootstrap** | Resampling blocks of consecutive observations to estimate uncertainty while preserving dependence |
| **Box–Cox** | Family of power transforms; λ = 0 is the log |
| **Breusch–Godfrey** | Test for autocorrelation valid with lagged dependent variables |
| **Breusch–Pagan / White** | Tests for heteroskedasticity |
| **Champion / challenger** | The selected model, and an alternative kept to test how much conclusions depend on model choice |
| **Chow test** | F-test of whether coefficients differ between two sub-samples |
| **Cointegration** | Non-stationary series whose linear combination is stationary: a genuine long-run relationship |
| **Cook's distance** | How much all fitted values change when one observation is dropped |
| **COVID dummy** | Indicator for 2020 Q2 – 2021 Q4, when policy support broke the usual link between the economy and losses |
| **CUSUM** | Test for parameter instability using cumulative recursive residuals |
| **DFBETAS** | Change in one coefficient, in standard errors, when one observation is dropped |
| **Driscoll–Kraay** | Panel standard errors robust to cross-sectional and serial correlation |
| **Dummy variable** | 0/1 regressor that shifts the intercept for a group or period |
| **Dynamic model** | Includes the dependent variable's own past (lagged y) |
| **Elastic Net** | Regularisation mixing Ridge and Lasso penalties |
| **Engle–Granger** | Cointegration test: are levels-regression residuals stationary? |
| **Fixed effects** | Unit-specific intercepts in a panel |
| **FWL theorem** | A multiple-regression coefficient equals the slope of y-residuals on x-residuals after partialling out the other regressors |
| **Heteroskedasticity** | Error variance that changes across observations |
| **IFRS 9** | Accounting standard requiring forward-looking expected credit loss provisions |
| **Impairment vs write-off** | Impairment: provision for expected loss; write-off: debt removed from the books when deemed unrecoverable (later) |
| **Interaction** | Product of regressors, letting one variable's effect depend on another |
| **Jump-off** | The starting quarter of a projection (here 2024 Q4) |
| **Lasso** | L1-penalised regression; sets some coefficients to exactly zero |
| **Leverage** | Diagonal of the hat matrix: how unusual an observation's regressors are |
| **Logit** | ln(p / (1 − p)); maps a rate in (0, 1) to the whole real line |
| **Loss rate** | Write-offs as a percentage of balances, here annualised and lagged-balance based |
| **Model risk** | Risk of bad decisions from models that are wrong or misused |
| **Multicollinearity** | Strong correlation among regressors, inflating standard errors |
| **Newey–West (HAC)** | Standard errors robust to heteroskedasticity and autocorrelation |
| **Normal equation** | X'Xβ = X'y, the first-order condition of least squares |
| **Omitted-variable bias** | Bias from leaving out a variable that matters and is correlated with included regressors |
| **Overfitting** | Fitting noise: good in-sample fit, poor out-of-sample performance |
| **Overlay** | Documented adjustment to model output for a known weakness |
| **Persistence (ρ)** | Coefficient on lagged y; how much of a shock remains later |
| **Prediction interval** | Range for one future outcome (includes the error variance) |
| **QR decomposition** | X = QR, a numerically stable way to solve least squares |
| **Quantile regression** | Models a percentile of y rather than its mean |
| **RESET** | Test for omitted non-linearity using powers of fitted values |
| **Reverse stress test** | Find how severe a scenario must be to breach a threshold |
| **Ridge** | L2-penalised regression; shrinks coefficients |
| **Satellite model** | Regression linking a portfolio's loss rate to macroeconomic drivers |
| **Sign rule** | Requirement that each coefficient has its economically expected sign |
| **SS1/23** | PRA supervisory statement on model risk management principles for banks |
| **Spurious regression** | Apparent relationship between unrelated trending series |
| **Stationarity** | Constant mean, variance and autocorrelation over time |
| **Static balance sheet** | Assumption that portfolio balances stay at the jump-off level |
| **Trailing four-quarter rate** | Sum of the last four quarters' write-offs over average balance |
| **Unit root** | Non-stationarity of the random-walk type |
| **VIF** | Variance inflation factor, 1/(1 − R²ⱼ) |
| **WLS** | Weighted least squares; down-weights noisier observations |
